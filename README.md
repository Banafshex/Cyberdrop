# CYBERDROP

> انتقال فایل نقطه‌به‌نقطه روی اینترنت — **بدون سرور**، رمزنگاری‌شده، با قابلیت ادامه بعد از قطعی.

اپلیکیشن اندروید برای فرستادن فایل بین دو گوشی، بدون آپلود روی هیچ فضای ابری.
فایل مستقیماً از گوشی شما به گوشی گیرنده می‌رود و فقط `WebRTC DataChannel`
(رمزنگاری DTLS/SCTP) در میان است. هیچ اکانت، ثبت‌نام یا سروری لازم نیست.

## چطور کار می‌کند؟

```
   فرستنده                                  گیرنده
 ┌──────────┐                            ┌──────────┐
 │ فایل انتخابی │                          │ شناسهٔ من │
 └────┬─────┘                            └────┬─────┘
      │  ① تبادل SDP از طریق یک بروکر عمومی MQTT (فقط چند کیلوبایت)
      └─────────────────┬──────────────────────┘
                        ▼
     ② کانال دادهٔ WebRTC، مستقیم و رمزنگاری‌شده (DTLS)
        ┌────────────────────────────────────┐
        │  chunk 64KB → تأیید → chunk بعدی   │
        │  آفست ذخیره‌شده → ادامه پس از قطعی │
        └────────────────────────────────────┘
```

* **شناسهٔ دستگاه** در اولین اجرا ساخته می‌شود (مثل `CD-7F3A-92K1`) و ثابت می‌ماند.
  فرستنده فقط همین شناسه را وارد می‌کند.
* برای پیدا کردن همدیگر، از **بروکرهای عمومی و رایگان MQTT** (`broker.emqx.io`،
  `broker.hivemq.com`، `test.mosquitto.org`) استفاده می‌شود؛ فقط برای رد و بدل کردن
  اطلاعات اتصال (SDP). محتوای فایل هرگز از این کانال عبور نمی‌کند.
* خودِ فایل روی کانال `WebRTC DataChannel` می‌رود: مستقیم بین دو گوشی، رمزنگاری‌شده،
  و بدون هیچ واسطه‌ای که بتواند محتوا را ببیند.
* نام تاپیک‌ها هشِ SHA-256 شناسه است تا شناسه روی بروکر عمومی لو نرود.

## ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| **ادامهٔ خودکار انتقال** | بایت‌های رسیده در فایل `*.part` ذخیره می‌شوند؛ اگر نت قطع شود یا برنامه بسته شود، بعد از وصل شدن دوباره از همان نقطه ادامه می‌یابد (تا ۸ بار تلاش مجدد). |
| **محدودیت حجم شفاف** | سقف هر فایل (پیش‌فرض ۴ گیگابایت، قابل تغییر تا ۸) هم در صفحهٔ ارسال و هم در تنظیمات نمایش داده می‌شود. |
| **تأیید گیرنده** | تا وقتی گیرنده «تأیید» نزند، حتی یک بایت هم فرستاده نمی‌شود. |
| **بررسی یکپارچگی** | هش SHA-256 فایل در دو طرف مقایسه می‌شود. |
| **رابط سایبرپانک** | زمینهٔ مشکی، شبکهٔ متحرک، نئون فیروزه‌ای، بدون شلوغی رنگی؛ همه‌چیز با فونت مونو و سبک HUD. |
| **بدون مجوز اضافه** | فقط `INTERNET` و `WAKE_LOCK`. مجوزهای دوربین/میکروفونِ کتابخانهٔ WebRTC حذف شده‌اند. |

## محدودیت‌ها (صادقانه)

* در بعضی شبکه‌های موبایل با **NAT متقارن/CGNAT**، ارتباط مستقیم برقرار نمی‌شود
  (بدون سرور رلهٔ TURN، این محدودیت ذاتی WebRTC است). در تنظیمات می‌توانید نشانی
  یک TURN رایگان را وارد کنید تا مسیر پشتیبان داشته باشید.
* هر دو گوشی باید **همزمان** برنامه را باز داشته باشند؛ فرستنده تا تأیید گیرنده صبر می‌کند.
* در حالت فعلی یک انتقال در هر لحظه پشتیبانی می‌شود (ارسال یا دریافت).
* فایل‌ها در پوشهٔ اختصاصی برنامه ذخیره می‌شوند
  (`Android/data/com.cyberdrop.transfer/files/Cyberdrop`) و با دکمهٔ «اشتراک‌گذاری»
  به هر برنامه‌ای قابل فرستادن‌اند.

## ساخت

```bash
# پیش‌نیاز: JDK 17 و Android SDK (compileSdk 34)
gradle assembleRelease      # یا در Android Studio: Build > Build APK(s)
```

هر push به مخزن، APK را روی GitHub Actions می‌سازد و در Releases می‌گذارد
(`.github/workflows/android.yml`).

> کلید امضای نسخهٔ انتشار (`keystore/cyberdrop.p12`، رمز `cyberdrop2024`) برای
> سادگی در مخزن است تا بروزرسانی‌ها روی هم نصب شوند. اگر مخزن را عمومی می‌کنید و
> برایتان مهم است، این کلید را با کلید خودتان عوض کنید.

## ساختار کد

```
app/src/main/java/com/cyberdrop/transfer/
├── core/        شناسهٔ دستگاه، تنظیمات، فرمت اعداد
├── net/         Signaling (MQTT عمومی) برای تبادل SDP
├── transfer/    هستهٔ WebRTC + پروتکل انتقال و ادامه‌دهی
└── ui/          تم سایبرپانک (Compose) و صفحه‌ها
```
